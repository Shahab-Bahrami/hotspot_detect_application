# SenseNet hotspot application — Version 2 archive

This directory preserves the previous application exactly as it existed before
the Version 3 migration on 4 September 2026:

- `fire_gui/` contains the Version 2 Flask source, neural/classical models,
  templates, map data, and original build files.
- Generated Version 2 packages and native build outputs are preserved under
  `artifacts/archive/version2/`.

The archive is retained for reproducibility and comparison. Its original paths
and launch instructions are historical and are not the maintained application.
Use `apps/fire_gui_v3/` for current work.
