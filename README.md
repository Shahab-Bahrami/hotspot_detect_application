# Applications

- `fire_gui_v3/` — maintained SenseNet Hotspot Intelligence Version 3 source,
  models, launchers, and native build definitions.
- `archive/version2/fire_gui/` — frozen Version 2 source and model artifacts.

Version 3 is a research-evaluation application. It exposes two distinct scores
because the internal study found that strictly prior operational labels add
strong signal but can encode Sitrep membership or verification policy. Neither
score is autonomous dispatch guidance.
